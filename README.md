# Numerical-Exploration-of-Quantum-Dynamics-in-Potential-Wells-and-Barriers
Solve the time-dependent Schrödinger equation numerically for different potentials:  Infinite square well (benchmark case, compare with analytic solutions).  Finite potential well (bound vs scattering states).  Potential barrier (quantum tunneling).  Harmonic oscillator (Gaussian wavepacket evolution).
